Step 3 · permanent action

Confirm & save this entry?

The entry will be written to the selected Project through your authenticated Supabase session. Owner/editor permission is checked again by RLS.

Update decision lifecycle

Close this decision?

The entry will remain in Project Memory, but its result becomes decided. It will no longer be presented to future AI sessions as an open decision.

Permanent deletion · Owner only

Delete this entry permanently?

This removes the entry from Project Memory and future AI context. Prefer editing or closing a decision if the historical record should remain available.

Permanent deletion · Owner only

Delete Project permanently?

This will permanently remove the Project, its Project Memory entries, member associations, and AI connection tokens. This action cannot be undone.
